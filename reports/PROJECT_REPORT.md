# AI Data Analytics — NGO Impact & Donation Analytics

## 1. Abstract
This project demonstrates an end-to-end analytics workflow for understanding donation patterns, beneficiary outcomes, volunteer contributions and program-level efficiency.

## 2. Problem Statement
Non-profit organizations can generate multiple operational datasets. Without structured analysis, it can be difficult to identify funding trends, compare program activity, understand beneficiary outcomes and monitor volunteer contribution.

## 3. Objectives
- Analyze donation volume and monetary contribution.
- Compare funding across programs and states.
- Measure beneficiary attendance and outcome indicators.
- Analyze volunteer participation and hours.
- Demonstrate exploratory donor segmentation with K-Means.
- Present results through an interactive Streamlit dashboard.

## 4. Dataset
Four synthetic CSV datasets are included: donations, beneficiaries, volunteers and programs.

## 5. Methodology
Data generation → validation → cleaning → exploratory data analysis → KPI calculation → visualization → exploratory ML → dashboard.

## 6. Key Analytical Modules
1. Donation & Donor Analysis
2. Beneficiary Impact Analysis
3. Program Efficiency Analysis
4. Volunteer Analytics
5. Donor Segmentation & Machine Learning
6. Time-Series & Impact Trends

## 7. Technology Stack
Python, Pandas, NumPy, Scikit-learn, Plotly, Streamlit and Jupyter.

## 8. Limitations
The datasets are synthetic and therefore do not establish conclusions about InAmigos Foundation, its donors, beneficiaries or programs. The ML component is demonstrative and uses aggregated donor-type features.

## 9. Future Scope
- Integrate authorized real-world datasets.
- Add automated data validation.
- Add stronger donor-level features where privacy rules permit.
- Compare multiple clustering methods.
- Add role-based dashboard access.
- Deploy the dashboard with secure authentication.
